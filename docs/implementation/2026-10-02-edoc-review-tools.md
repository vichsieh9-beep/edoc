# EDoc 修訂建議：狀態配色、操作整理、逐項備註與發布入口

使用者已授權本機實作上述四項；不 Commit、Push、部署、建立雲端資源或呼叫付費 AI。

## 完成內容

- 正文編號與右側編號共用狀態：採納為淺綠色與 ✓，不採納為淺紅色與 ×，待討論為淺藍色與 ▴。選取外框仍用藍色，不覆蓋狀態色；逐項決定按鈕的選中配色一致。
- 完整歷程、重新比較、撤回及批次操作置於「更多操作」。移除原常駐整份討論輸入區；先前留言仍可由完整歷程讀取。保持原有權限檢查及重新比較時的草稿備份保護。
- 每項修訂增加原生 details 備註區，和修改內容分開收合。以既有 /suggestions/comment 的 itemIds 綁定單項，顯示伺服器保存的姓名、日期、文字，並讀取已存在的逐項決定備註；不修改 Worker 資料結構。
- 備註追加到歷程，不覆寫舊記錄；以文字節點渲染，保留換行並防止留言成為可執行 HTML。空白不送出；暫存輸入及收合狀態在本頁切換篩選、審核其他項目時保留。傳輸失敗保留內容，沿用既有相同操作識別碼重試，避免成功但回應遺失後重複留言。未送出的備註暫存在頁面記憶體，重新整理不保證保留；已儲存備註可重新讀取。
- 具發布權限的人在固定標頭看到「發布新版」。未有尚未發布、未被鎖定的採納內容時停用；側欄操作進行中也停用。保留伺服器的正式基準、版本、預覽雜湊及權限核對。
- 發布入口先開預覽對話框，顯示採納／不採納／待討論統計與部分發布提示，確認才呼叫發布。返回、Escape、點擊遮罩會回到建議檢視；正式內容和版號在成功儲存後才更新。不採納、待討論及所有備註保留於完整歷程，不寫入正式正文。新增 modal 可選 onClose 回呼，不改其他對話框行為。
