# 本機修訂操作與輸入穩定性修正

本輪範圍：切換標記取消修訂選取、輸入跳行、移除不可點的「顯示項目」文字、返回正式版二次確認、完整歷程可開關。僅本機；沒有 Commit、Push、部署、雲端資源或付費 AI。

## 行為

- 切換所有／簡單標記時清除正文定位框、左右編號的選取狀態與卡片選取，不改動修訂決定或原生文字游標。
- 原先輸入前移除刪除比較片段，再延遲 150 ms 重畫，會讓後續段落短暫上移。現在輸入完成後在 microtask 更新差異，於下次繪製前補回；保留原始 Text 節點供原生復原操作使用。
- 中文組字期間保留整段刪除片段占位，不在組字中重建編輯節點；組字結束（包括取消、內容未變）強制補回所有比較片段。
- 刪除「顯示項目」可見文字，保留有功能的狀態篩選，預設選項改成「全部修訂」；原 aria-label 保留。
- 返回正式版先顯示「繼續檢視／確認返回」。準確告知不會刪除建議、採納決定與已儲存備註。有未儲存備註時，補充僅暫存於此頁、重新整理／關閉會遺失。取消不清掉卡片或備註狀態。
- 完整歷程以同一按鈕展開／收起，提供 aria-expanded 與 aria-controls。慢速回應完成不會自動重新展開已收起的區塊。

## 驗證與限制

- 新增 tests/review-controls.spec.js：清除選取、篩選、歷程開關、返回確認與完整資料保存。
- tests/caret-navigation.spec.js：以逐畫格量測段落座標，重現原本跳行；測試輸入、刪字、組字開始／結束／取消及箭頭游標。
- 舊有返回按鈕測試更新為先確認。舊有切換標記測試改成預期清除選取。
- WebKit 原生 Undo 可能合併多筆輸入；若連原本選取的修訂也還原，選取應清除。測試依實際還原內容斷言，而非依賴舊版 150 ms 延遲掩蓋中間狀態。
- 中文測試使用瀏覽器 composition 事件與文字插入，未直接驗收 macOS 注音／倉頡候選窗。
- 一次全套測試的既有 publication-recovery 案例收到 writing 而非 saved。單獨重跑 3 次皆通過；該測試會立即重啟背景寫入工作，未修改該後端流程。
- 正式 document.json、worker/wrangler.toml、引擎版號及 Pages workflow 雜湊均與本輪開始一致。
