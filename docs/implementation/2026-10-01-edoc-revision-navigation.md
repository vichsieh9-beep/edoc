# 修訂編號與雙向定位（本機）

26/10/01。範圍為已核定的草稿、正式版本比較、私人修訂建議顯示與定位，不更動正式文件或歷史版本。

## 行為

- 正文與右側卡依文件順序顯示一致的 01、02…；以既有修訂卡為單位，私人建議原始項目 ID 不變。
- 點正文編號選取右卡，必要時捲動右欄；點右卡／編號選取正文，只有正文超出可視範圍才捲動。兩側同步藍框，一次只選一項。
- 草稿點正文仍正常編輯，點定位控制不搶走既有文字游標。編號與選取框位於 #doc 外，不進入暫存、送出、複製內容或列印／PDF。
- 簡單標記保留刪段原位置的編號與定位空隙，右卡仍保留原文。連續刪段的編號在同一空隙以可捲動的直列呈現。
- 切換模式、採納／不採納、篩選不改編號；點篩選後隱藏卡的正文編號會顯示全部並定位。草稿重算編號時保留同段選取，該項撤銷後清除選取。
- 內容重複的刪段依固定比較來源的區塊位置辨識，避免取消前一項後丟失後一項選取。新增 HR／圖片以對應媒體定位，避免錯指下一段。
