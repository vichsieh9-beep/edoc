## 本輪取捨與代價

| 決策 | 理由與代價 |
|---|---|
| 原子連結輪替 | 回應遺失不產生兩條有效連結；任一步失敗回滾，保留原連結。 |
| 伺服器正式 snapshot／current 讀取 | 不用預覽推造官方版本；代價是額外授權讀取，斷線時需重試。 |
| 新建議發布單獨驗證 PDF | Pages 上線不足以證明 PDF 可下載；舊直接發布維持既有契約，後續可另外整理。 |
| 決定操作等待回應 | 防止快速連按使用舊 revision 而遺失決定；代價是需短暫等待。 |
| PDF 確認後清除追蹤，恢復時不倒退 latest | 保留尚未完成的 Pages／PDF 查詢，不把新正式版或草稿覆蓋；讀取故障仍可續查。 |
| 隔離且可丟棄的 loopback 預覽 | 可讓使用者試操作而不接 production；資料只在記憶體，關閉／重啟即清除，不生成官方 PDF。 |
